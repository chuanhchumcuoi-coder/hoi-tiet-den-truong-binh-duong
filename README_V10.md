# V10 - Luu vi tri nha bang GPS

Tinh nang thu nghiem:
- Dinh vi GPS nhu ban hien tai.
- Khi dang o nha, bam `Luu vi tri hien tai lam nha`.
- Toa do nha duoc luu trong `localStorage` cua trinh duyet, khong luu tren server.
- Co the cap nhat hoac xoa vi tri nha.
- Ho tro 3 huong hanh trinh: Vi tri hien tai -> Truong, Nha -> Truong, Truong -> Nha.
- Hien marker nha tren ban do.
